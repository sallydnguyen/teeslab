Ứng dụng di động PWA giả lập màu film 35mm (**Fujifilm, Kodak, CineStill, Ilford**) theo cơ chế phối ghép **Body + Lens + Film Stock**, kết hợp bộ nhận diện cảm biến điện thoại tự động qua EXIF (hỗ trợ đến **iPhone 18 Series, Galaxy S26 Ultra, Xiaomi 17 Leica, Pixel 11 Pro, OPPO Find X9 / Vivo X300**).

## Đồng bộ thiết lập qua GitHub Gist

Tee's Lab có thể tự sao lưu và đồng bộ hai chiều thiết lập máy ảnh cùng recipe giữa các thiết bị qua một GitHub Gist riêng tư. Chạm biểu tượng ☁️ trên thanh trên cùng, nhập GitHub Personal Access Token có quyền `gist`, rồi chọn **Connect and sync**. Thay đổi được đẩy lên sau một khoảng chờ ngắn; khi mở lại ứng dụng hoặc quay lại tab, app sẽ kiểm tra bản mới nhất.

> Đồng bộ gồm cấu hình máy ảnh, thông số chỉnh ảnh và recipe đã lưu. Ảnh nguồn, ảnh đã xuất và ảnh cuộn camera vẫn nằm trên thiết bị hiện tại.
